# Community Code of Conduct

## Our standard

The ArSonKuPik public repository welcomes respectful, technically useful participation from users, testers, creators and contributors.

Positive participation includes:

- communicating clearly and professionally;
- focusing criticism on observable behaviour, evidence and reproducible results;
- respecting different experience levels, languages, platforms and workflows;
- protecting customer, project, activation and security information; and
- accepting reasonable maintainer decisions about product scope and repository boundaries.

Unacceptable behaviour includes:

- harassment, intimidation, insults or discriminatory language;
- publishing personal, customer, activation, order or security-sensitive information;
- promoting cracks, activation bypasses, unofficial mirrors or modified packages;
- deliberately misleading claims about releases, compatibility, ownership or licensing;
- spam, unrelated promotion or repeated off-topic demands; and
- attempts to pressure others into disclosing proprietary source or private credentials.

## Scope

This code applies to issues, pull requests, reviews, discussions and other public interactions associated with this repository.

## Enforcement

Maintainers may edit, hide, lock or remove content; close issues or pull requests; and restrict participation when behaviour conflicts with this code or creates safety, privacy, security or legal risk.

Report conduct concerns privately through the repository owner's GitHub profile or another private channel identified by the maintainer. Do not publish sensitive evidence in a public issue.

Enforcement decisions will consider context, severity, repetition, user safety and the integrity of the public product surface.
