Instalasi dan verifikasi — empat langkah
  1. Unduh hanya dari rilis resmi.
  2. Unduh SHA256SUMS.txt dari rilis yang sama.
  3. Hitung SHA-256 untuk file yang benar-benar Anda unduh.
  4. Instal atau buka paket hanya ketika checksum cocok.
Get-FileHash .\ArSonKuPik-v0.5.23-Windows-x64-Setup.exe -Algorithm SHA256Buka SHA256SUMS.txt

Paket Windows belum memiliki commercial code signing. Paket macOS hanya ad-hoc signed dan belum dinotarization. Biarkan proteksi normal sistem operasi aktif dan hentikan jika checksum berbeda.

Distribusi transparan: website hanya mengarah ke rilis repository resmi, memvalidasi URL rilis sebelum menerapkannya, dan menjaga verifikasi SHA-256 tetap terlihat.

Pertanyaan yang sering diajukan

Hal penting sebelum mengunduh.

Apa itu ArSonKuPik?

Audio enhancer VST3 dan Standalone untuk Windows dan macOS yang fokus serta musikal untuk master, mix bus, track, vokal, podcast, processing kreatif, dan mendengarkan sehari-hari.

Apa yang membuat Mas Ari Signature berbeda?

Ini adalah satu-satunya enhancement engine di balik seluruh preset, dibuat agar musik familiar terasa lebih hidup, detail halus lebih mudah terdengar, dan dimensi terasa meyakinkan tanpa rangkaian teknis yang rumit.

VST3 atau Standalone?

VST3 berjalan di dalam DAW kompatibel. Standalone berjalan sebagai aplikasi terpisah dan membutuhkan input serta output yang dipilih. Buka panduan penggunaan pemula.

Apakah bisa enhancing YouTube, Spotify, dan seluruh suara Windows?

Bisa. Route playback Windows ke VB-CABLE, pilih CABLE Output sebagai input ArSonKuPik Standalone, lalu pilih speaker, soundcard, audio interface, headphone, atau TWS sebagai output. Ikuti panduan routing.

Mengapa Standalone dapat terbuka tetapi tidak ada suara?

Standalone tidak otomatis menangkap audio laptop. Pastikan input benar-benar membawa sinyal dan output mengarah ke perangkat dengar yang nyata. Panduan menyediakan checklist no-sound.

Berapa lama full editing tersedia?

Seluruh preset dan kontrol editing tersedia selama 365 hari sejak pertama dijalankan pada tiap komputer, tanpa akun, kartu, langganan, tagihan otomatis, atau kewajiban membeli.

Apa yang terjadi setelah full editing berakhir?

Project lama, nilai tersimpan, meter, playback automation, dan processing audio dirancang tetap berjalan dalam mode project-safe read-only. Aktivasi opsional hanya relevan untuk melanjutkan editing.

Apakah boleh dipakai untuk pekerjaan berbayar?

Ya, selama evaluasi untuk pekerjaan produksi audio personal dan komersial, tunduk pada EULA. Audio dan project tetap milik Anda.

Apakah aplikasi mengunggah audio atau melacak penggunaan?

Operasi normal tidak memiliki unggahan audio, crash analytics, atau usage analytics yang disengaja. Satu pemeriksaan metadata rilis terbaru dapat terjadi setelah 30 detik, maksimal sekali per 24 jam; pemeriksaan manual juga tersedia.

Mengapa Windows atau macOS dapat menampilkan peringatan keamanan?

Paket Windows belum ditandatangani secara komersial dan paket macOS belum dinotarization. Unduh hanya dari rilis resmi, verifikasi SHA-256, dan biarkan proteksi normal sistem operasi aktif.
