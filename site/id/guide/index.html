Workflow 01 · Produksi

Gunakan VST3 di dalam DAW yang kompatibel.

Ini adalah pilihan yang benar ketika audio sudah berada di dalam project produksi musik, recording, editing, atau mixing. ArSonKuPik menjadi effect pada track, bus, atau master.

Unduh VST3 + Standalone
01

Instal paket resmi

Installer Windows menempatkan VST3 di lokasi standar dan juga menyertakan Standalone. Pada macOS, instal atau salin VST3 dari paket resmi.

02

Buka DAW dan scan ulang plug-in

Gunakan plug-in manager atau perintah rescan pada DAW jika ArSonKuPik belum langsung muncul.

03

Pasang ArSonKuPik pada posisi yang diperlukan

Gunakan pada track, vokal, instrumen, mix bus, atau master. Mulai dengan satu instance agar hasil mudah dinilai.

04

Mulai dari Signature Balanced

Putar material familiar, pilih Signature Balanced, lalu gerakkan satu kontrol setiap kali. Gunakan preset spesifik hanya ketika sesuai dengan sumber.

05

Bandingkan pada level yang masuk akal

Gain Match OFF mempertahankan impact enhancement penuh. Aktifkan hanya saat ingin membandingkan tone pada level yang lebih setara.

Workflow 02 · Aplikasi terpisah

Gunakan Standalone dengan input dan output audio yang dipilih.

Standalone berjalan tanpa DAW, tetapi tetap membutuhkan sumber audio. Pilih input yang membawa suara dan output tempat Anda ingin mendengarkan.

Penting: hanya membuka Standalone tidak otomatis menangkap seluruh suara laptop. Gunakan workflow VB-CABLE berikut untuk system audio Windows.
01

Buka ArSonKuPik Standalone

Gunakan aplikasi hasil instalasi atau paket Standalone resmi sesuai sistem operasi.

02

Pilih input audio

Pilih audio interface, soundcard, input mikrofon/line, sumber loopback, atau virtual cable yang benar-benar membawa sinyal.

03

Pilih output untuk mendengarkan

Pilih speaker laptop, audio interface, soundcard USB, headphone, atau output stereo Bluetooth/TWS.

04

Samakan sample rate dan gunakan buffer stabil

Gunakan sample rate yang sama pada sumber dan output bila memungkinkan. Naikkan buffer jika terdengar click; turunkan hanya ketika latency penting.

05

Pastikan meter bergerak sebelum tuning

Jangan mengubah preset sebelum meter input dan output menunjukkan sinyal yang valid. Setelah itu mulai dari Signature Balanced.

Untuk mendengarkan musikPrioritaskan playback yang stabil dan bersih, bukan buffer sekecil mungkin.
Untuk monitoring liveGunakan audio interface berkabel ketika latency rendah dibutuhkan.
Workflow 03 · System audio Windows

Enhance YouTube, Spotify, dan seluruh suara laptop melalui VB-CABLE.

VB-CABLE menjadi jalur virtual antara playback Windows dan ArSonKuPik Standalone. Hasil yang sudah diproses kemudian keluar dari ArSonKuPik menuju perangkat dengar yang nyata.

Buka website resmi VB-CABLE

VB-CABLE adalah software pihak ketiga dari VB-Audio. ArSonKuPik dan MasArray tidak berafiliasi atau memperoleh endorsement dari VB-Audio.

Penamaannya memang seperti ini: Windows mengirim audio ke CABLE Input sebagai playback device. ArSonKuPik menerima stream yang sama dari CABLE Output sebagai input/recording device.
01

Instal VB-CABLE lalu restart Windows

Unduh dari website resmi VB-Audio, extract paket, jalankan setup yang sesuai sebagai Administrator, lalu reboot.

02

Kirim suara Windows ke CABLE Input

Buka Windows Settings → System → Sound, lalu pilih CABLE Input (VB-Audio Virtual Cable) sebagai output device.

03

Pilih CABLE Output di ArSonKuPik

Buka Standalone dan pilih CABLE Output (VB-Audio Virtual Cable) sebagai input source.

04

Pilih perangkat dengar yang sebenarnya

Pilih speaker laptop, audio device, soundcard, audio interface, headphone berkabel, atau TWS sebagai output ArSonKuPik.

05

Putar musik familiar dan verifikasi routing

Jalankan YouTube atau Spotify. Pastikan meter ArSonKuPik bergerak dan suara yang sudah diproses keluar melalui output pilihan.

06

Kembalikan output Windows setelah selesai

Jika ArSonKuPik ditutup, ubah output Windows dari CABLE Input kembali ke speaker atau headphone normal.

Untuk TWS: pilih output Stereo/A2DP, bukan Hands-Free atau Headset. Menggunakan mikrofon TWS secara bersamaan dapat memaksa Windows masuk ke profile komunikasi dengan kualitas lebih rendah. Latency Bluetooth normal untuk mendengarkan musik, tetapi kurang ideal untuk monitoring live.
Setting pertama

Buat hasil pertama mudah terasa tanpa processing berlebihan.

Gunakan material yang sudah Anda kenal. Pastikan routing benar terlebih dahulu, lalu nilai satu perubahan setiap kali.

01

Pilih Signature Balanced

Preset ini adalah titik awal paling berguna untuk memahami karakter Mas Ari Signature engine.

02

Jaga source dan output agar tidak clipping

Jika output menjadi terlalu tinggi, turunkan Output Trim sebelum menambah enhancement.

03

Gerakkan satu kontrol setiap kali

Enhance mengatur jumlah keseluruhan; gunakan Bass, Treble, Vocal, dan Stereo hanya untuk kebutuhan yang jelas.

04

Gunakan bypass dan Gain Match dengan tujuan jelas

Bypass menjawab “apakah saya lebih menyukai hasil processing?” Gain Match membantu menjawab “apakah tone lebih baik pada level yang mirip?”

Troubleshooting cepat

Ketika tidak ada suara, periksa routing sebelum DSP.

Sebagian besar masalah awal berasal dari input, output, atau playback device Windows yang salah.

Standalone terbuka tetapi meter tidak bergerak

Pastikan input yang dipilih benar-benar membawa audio. Untuk suara laptop melalui VB-CABLE, output Windows harus CABLE Input dan input ArSonKuPik harus CABLE Output.

Meter bergerak tetapi tidak terdengar suara

Periksa output ArSonKuPik dan volumenya. Output harus speaker, soundcard, audio interface, headphone, atau TWS yang nyata—bukan CABLE Input atau CABLE Output.

Terdengar suara dry dan processed bersamaan

Nonaktifkan jalur monitoring Windows “Listen to this device” dan pastikan hanya ArSonKuPik yang mengirim sinyal virtual cable ke perangkat dengar.

Terdengar click, dropout, atau playback tidak stabil

Samakan sample rate bila memungkinkan, tutup aplikasi lain yang memakai exclusive mode, lalu naikkan audio buffer sampai playback stabil.

Suara TWS tipis atau seperti telepon

Pilih output Stereo/A2DP dan hindari menggunakan mikrofon TWS secara bersamaan. Mode Hands-Free/Headset memiliki kualitas playback lebih rendah.

VST3 tidak muncul di DAW

Pastikan paket VST3 sudah terpasang, buka plug-in manager DAW, lalu lakukan full rescan. Kompatibilitas tetap bergantung pada host dan sistem yang digunakan.
