Installation and verification — four steps
  1. Download only from the official release.
  2. Download SHA256SUMS.txt from the same release.
  3. Calculate SHA-256 for the exact file you downloaded.
  4. Install or open the package only when the checksum matches.
Get-FileHash .\ArSonKuPik-v0.5.23-Windows-x64-Setup.exe -Algorithm SHA256Open SHA256SUMS.txt

Windows packages are not commercially code-signed. macOS packages are ad-hoc signed and not notarized. Keep normal operating-system security enabled and stop when the checksum differs.

Transparent distribution: the website points only to official repository releases, validates release URLs before applying them and keeps SHA-256 verification visible.

Frequently asked questions

The essentials before you download.

What is ArSonKuPik?

A focused, musical Windows and macOS VST3 and Standalone audio enhancer for master, mix bus, tracks, vocals, podcasts, creative processing and everyday listening.

What makes Mas Ari Signature special?

It is the single enhancement engine behind every preset, created to make familiar music feel more alive, reveal fine detail and produce a convincing live-like dimension without requiring a complex chain.

VST3 or Standalone?

VST3 runs inside a compatible DAW. Standalone runs as a separate application and needs a selected input and output. Open the beginner usage guide.

Can it enhance YouTube, Spotify and all Windows sound?

Yes. Route Windows playback to VB-CABLE, select CABLE Output as the ArSonKuPik Standalone input, then select your speaker, soundcard, audio interface, headphones or TWS as output. Follow the routing guide.

Why can Standalone open without producing sound?

Standalone does not automatically capture laptop audio. Verify that its input carries a signal and that its output is the real listening device. The guide includes a no-sound checklist.

How long is full editing available?

Every preset and editing control is available for 365 days from first launch on each computer, without an account, card, subscription, automatic charge or purchase obligation.

What happens after full editing ends?

Existing projects, saved values, meters, automation playback and audio processing are designed to continue in project-safe read-only mode. Optional activation is relevant only for continued editing.

Can I use it for paid work?

Yes, during the evaluation for personal and commercial audio-production work, subject to the EULA. Your audio and projects remain yours.

Does it upload audio or track usage?

Normal operation has no intentional audio upload, crash analytics or usage analytics. One quiet latest-release metadata check may occur after 30 seconds, no more than once per 24 hours; manual checks are also available.

Why can Windows or macOS show a security warning?

Windows packages are unsigned and macOS packages are not notarized. Download only from the official release, verify SHA-256 and keep normal operating-system security enabled.
