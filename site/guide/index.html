Workflow 01 · Production

Use VST3 inside a compatible DAW.

This is the right choice when the audio already lives inside a music-production, recording, editing or mixing project. ArSonKuPik becomes an effect on a track, bus or master.

Download VST3 + Standalone
01

Install the official package

The Windows installer places the VST3 in the standard location and also includes Standalone. On macOS, install or copy the VST3 from the official package.

02

Open the DAW and rescan plug-ins

Use the DAW's plug-in manager or scan command when ArSonKuPik does not appear immediately.

03

Insert ArSonKuPik where you need it

Use it on an individual track, vocal, instrument, mix bus or master. Begin with one instance so the result remains easy to judge.

04

Start from Signature Balanced

Play familiar material, choose Signature Balanced, then move one control at a time. Use a role-specific preset only when it matches the source.

05

Compare at a sensible level

Gain Match is OFF for the intended full enhancement. Turn it ON only when you want a stricter level-equal comparison of tone.

Workflow 02 · Separate application

Use Standalone with a selected audio input and output.

Standalone runs without a DAW, but it still needs an audio source. Choose the input that carries the sound and the output device where you want to listen.

Important: opening Standalone alone does not automatically capture every sound from the laptop. Use the next workflow with VB-CABLE for Windows system audio.
01

Open ArSonKuPik Standalone

Use the installed application or the official Standalone package for your operating system.

02

Select the audio input

Choose the audio interface, soundcard, microphone/line input, loopback source or virtual cable that actually carries the signal.

03

Select the listening output

Choose the laptop speaker, audio interface, USB soundcard, headphones or Bluetooth/TWS stereo output.

04

Match sample rate and set a stable buffer

Use the same sample rate across the source and output when possible. Raise the buffer if you hear clicks; lower it only when latency matters.

05

Confirm meters move before tuning

Do not change presets until the input and output meters show a valid signal. Then start from Signature Balanced.

For normal listeningPrioritize stability and clean playback over the smallest possible buffer.
For live monitoringUse a wired audio interface when low latency matters.
Workflow 03 · Windows system audio

Enhance YouTube, Spotify and all laptop sound through VB-CABLE.

VB-CABLE acts as the virtual route between Windows playback and ArSonKuPik Standalone. The processed result then leaves ArSonKuPik through your real listening device.

The naming is intentional: Windows sends audio to CABLE Input as a playback device. ArSonKuPik receives that same stream from CABLE Output as an input/recording device.
01

Install VB-CABLE and restart Windows

Download it from the official VB-Audio website, extract the package, run the correct setup as Administrator, then reboot.

02

Send Windows sound to CABLE Input

Open Windows Settings → System → Sound and choose CABLE Input (VB-Audio Virtual Cable) as the output device.

03

Select CABLE Output inside ArSonKuPik

Open Standalone and select CABLE Output (VB-Audio Virtual Cable) as the input source.

04

Select the real listening device

Choose the laptop speaker, audio device, soundcard, audio interface, wired headphones or TWS as ArSonKuPik's output.

05

Play familiar music and verify the route

Start YouTube or Spotify. Confirm ArSonKuPik meters move and the processed sound reaches the selected output.

06

Restore the normal Windows output when finished

If ArSonKuPik is closed, switch Windows output from CABLE Input back to your normal speaker or headphones.

For TWS: select the Stereo/A2DP output, not Hands-Free or Headset mode. Using the TWS microphone at the same time can force Windows into a lower-quality communication profile. Bluetooth latency is normal for listening but not ideal for live monitoring.
First listening setup

Make the first result obvious without over-processing.

Use material you already know. Confirm the route first, then judge one change at a time.

01

Choose Signature Balanced

It is the most useful neutral starting point for understanding the Mas Ari Signature engine.

02

Keep the source and output below clipping

If the output becomes too hot, reduce Output Trim before pushing more enhancement.

03

Move one control at a time

Enhance sets the overall amount; then use Bass, Treble, Vocal and Stereo only to solve a clear listening need.

04

Use bypass and Gain Match deliberately

Bypass answers “do I prefer the processed result?” Gain Match helps answer “is the tone better at a similar level?”

Fast troubleshooting

When there is no sound, check the route before the DSP.

Most first-run problems come from selecting the wrong input, output or Windows playback device.

Standalone opens but no meter moves

Confirm the selected input actually carries audio. For laptop sound through VB-CABLE, Windows output must be CABLE Input and ArSonKuPik input must be CABLE Output.

Meters move but I hear nothing

Check ArSonKuPik's output device and its volume. The output should be the real speaker, soundcard, audio interface, headphones or TWS—not CABLE Input or CABLE Output.

I hear dry and processed audio together

Disable any extra Windows “Listen to this device” monitoring path and make sure only ArSonKuPik sends the virtual-cable signal to the listening device.

Clicks, dropouts or unstable playback

Match sample rates where possible, close competing exclusive-mode applications and increase the audio buffer until playback is stable.

TWS sounds thin or telephone-like

Select the Stereo/A2DP output and avoid using the TWS microphone simultaneously. Hands-Free/Headset mode has lower playback quality.

The VST3 does not appear in my DAW

Confirm you installed the VST3 package, open the DAW plug-in manager and perform a full rescan. Compatibility still depends on the specific host and system.
